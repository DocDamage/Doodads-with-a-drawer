# QA Record, 19 October 2026

MZ playtests of the backlog batches merged overnight (PRs #47–#52) and of the items PR #46 left untested. Run on a disposable copy of the QA test project.

## Setup

| | |
| :--- | :--- |
| RPG Maker MZ | Core scripts 1.10.0, PIXI 5.3.12 (WebGL 2) |
| NW.js | 0.48.4 (Chromium 85), the copy that ships with MZ, started with the project and `test` |
| Machine | Windows 11, NVIDIA GPU (24-bit depth buffer) |
| Test project | A copy of the QA project (`DocsDoodadsQA`): MZ's template plus MZ's sample maps; Town (35×40) used throughout |
| How | Scripted checks over the game's DevTools port: the functions the editor's buttons call, key events dispatched in the page, and screenshots of the game window, looked at one by one |
| Test models | `scratch/fixtures/morph_cube.glb` and `skinned_bar.glb`, made by Blender 4.5 (`scripts/make_model_fixtures.py`) |

## Not covered

- **A real lower-spec PC (B)** and **watching a new user (E)**: they need a different computer and a person. Nothing here stands in for them.
- **A physical gamepad**: the pad was simulated through the browser's Gamepad API, which is what MZ reads.
- **Screen readers**: names and roles are set and checked in tests; Narrator itself was not run.
- **Doodad packs between two real projects in MZ**: covered by `test_doodad_packs` with two sandbox projects and real files, not in a playtest.
- **The MZ editor reopening a map painted with Tiles**: the tiles are written into the map file the same way as region painting (checked in tests), but the MZ editor wasn't opened on the result.
